매칭 조건

고급 설정

등록된 보유 잉크를 모두 평가한 뒤 근거 확인·다양성·추가 시필 후보를 별도로 표시합니다. 특정 브랜드를 고르면 해당 브랜드의 후보도 따로 볼 수 있습니다. 정보 부족만으로 제품을 제외하지 않습니다.

점수는 개별 리뷰 + 개인 시필 + 닙의 일반적 경향을 이용한 비보정 비교용 추정이며, 리뷰 신뢰도와 별개입니다. 최종 잉크는 직접 고릅니다.

추천 결과

왼쪽에서 만년필 또는 잉크를 선택하고 추천을 실행하세요.

보유 0종 · 잉크 자료실

등록한 잉크마다 알려진 정보와 근거 수준을 보여줍니다. 자료 미확보는 성능이 낮다는 뜻이 아니에요. 객관적 수치가 없는 점도·표면장력·윤활성은 임의로 채우지 않습니다. 직접 시필 기록이나 외부 리뷰 링크로 조금씩 채워 갈 수 있어요.

No.제조사 · 잉크명색상리뷰 흐름건조(초)신뢰도상세
잉크 옆의 ‘자세히’를 누르면 리뷰 요약·원문 URL·검증 상태를 확인할 수 있습니다.

현재 잉입 현황 · 빠른 변경

기존 V4에 기록된 잉크는 과거 기록(현재 미확인)으로 표시합니다. 실제 상태를 확인해 저장하면 '확인된 잉입'으로 바뀝니다. 잉크 교체·세척 시 변경 이력이 자동으로 남습니다.

만년필을 선택하고 잉입·세척·미확인 상태 중 하나를 저장하세요. 새 잉크로 바꾸는 경우에는 기존 잉크를 제거하고 세척한 후 잉입했다는 전제로 기록됩니다.

되돌릴 수 있는 기록으로 남습니다. 저장 완료 표시를 확인하세요.

② 직접 시필 기록 · 특정 만년필 조건
실제로 사용해 확인한 경우에만 아래 체크를 선택하세요. 이 기록은 선택한 만년필에서만 추천 엔진의 흐름·윤활·번짐 점수에 반영됩니다. 다른 만년필로 일반화하지 않습니다.
③ 외부 리뷰 · 출처와 검증 상태

외부 리뷰는 독립적인 근거로 별도 보관합니다. 원문을 확인하지 않았다면 엔진 가산점에 사용하지 않습니다. 원문 확인 체크는 사용자 확인입니다. 리뷰 문장을 그대로 옮겨 적지 말고, 링크와 직접 정리한 짧은 메모만 남겨 주세요(저작권 보호).

데이터 백업·복원

데이터는 이 기기에만 저장돼요. 서버로 전송되지 않아 안전하지만, 기기를 잃어버리거나 브라우저 데이터를 지우면 함께 사라져요. 정기적으로 백업 파일을 받아 두세요. 다른 기기로 옮길 때도 백업 파일을 복원하면 됩니다.

백업에는 등록한 만년필·잉크와 모든 기록이 들어 있어요. 앨범·카메라로 넣은 사진이 있으면 .zip(데이터+사진), 없으면 .json 파일로 받아져요. 복원은 둘 다 됩니다.

엑셀로 저장 · 인쇄

컬렉션 전체를 엑셀(.xlsx) 파일로 저장하거나(만년필·잉크·잉입 기록·시필 노트 4개 시트), 인쇄·PDF로 만들 수 있어요. 엑셀 파일은 보기·정리용이고, 앱으로 되돌리는 복원은 JSON 백업을 쓰세요.
