# Pen & Ink Lab (공개판)

만년필·잉크 컬렉션을 기록하고, 어떤 펜에 어떤 잉크가 어울리는지 추천받는 웹앱이에요.

- **설치 파일·가입·로그인 없음** — 주소를 열고 홈 화면에 추가하면 끝
- **내 데이터는 내 기기에만 저장** — 서버·구글 계정·외부 접속 없음
- **인터넷 없이도 사용** (PWA), **엑셀(.xlsx) 저장 · 인쇄/PDF** 지원
- 백업(JSON)·복원으로 기기를 옮기고, 데이터가 쌓이면 **백업 알림**을 줘요

## 주요 기능

- 30초 시작: 만년필 1자루 + 잉크 1병으로 바로 첫 추천
- 잉크 114종·만년필 58모델 검색 자동완성 (한글 검색 지원)
- 만년필 카드에서 3탭 잉크 교체 (세척 기록 자동, 되돌리기)
- 펜·잉크·닙·시필 기록을 반영한 매칭 추천, 용어 ⓘ 설명
- **앨범·카메라 사진을 카드에** 넣기 (기기 안에만 저장, 백업은 .zip)
- **내가 쓰는 AI 앱으로 사진 읽기**(복사·붙여넣기): 제품 사진으로 등록, 시필 사진으로 초안 채우기 — 서버·API 키 없음

## 개발

```bash
npm install
npm run build      # site/ 생성 (정적 호스팅에 올리는 폴더)
npm run serve      # http://localhost:8080 미리보기
npm test           # 빌드 + 전체 자동 테스트
npm run release    # dist/ 에 배포 압축파일 생성
```

구조: `src/parts`(앱 소스 조각) → `scripts/build.mjs` → `site/` (`web/` 의 PWA 파일 포함).
