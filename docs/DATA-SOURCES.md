# 데이터 출처와 저작권 원칙

Pen & Ink Lab 이 어떤 데이터를 담고 있고, 어디서 왔고, 앞으로 데이터를 더할 때 무엇을 지켜야 하는지 정리한 문서입니다.

## 1. 앱에 들어 있는 데이터

| 데이터 | 내용 | 출처·성격 |
|---|---|---|
| 제품 카탈로그 (잉크 114종, 만년필 58모델) | 브랜드, 제품명, 대략적인 색 계열·색조, 특성(Standard/Sheen/Shimmer), 닙 종류, 한글 검색어 | 제품명은 공개된 사실입니다. 색 계열·특성은 작성자가 정리한 **참고용 분류**이며 제조사 공식 자료와 대조하는 작업은 아직 끝나지 않았습니다(`docs/MAINTAINERS.md` 점검표). 불확실한 특성은 `Standard` 로 둡니다. |
| 잉크 조사 자료 (리뷰 요약·수치) | **없음** | 개인 운영본이 쓰던 조사 시트는 외부 리뷰를 정리한 것이라 공개판에 **포함하지 않았습니다.** |
| 만년필·잉크 사진 | **없음** | 내장 이미지나 외부 이미지 링크를 두지 않습니다. 사용자가 앨범·카메라로 넣은 사진(기기 안 IndexedDB에만 저장)과 직접 입력한 사진 주소만 쓰입니다. |
| 사용자 컬렉션·기록 | 사용자가 입력한 모든 것 | 사용자의 **기기(브라우저) 안에만** 저장됩니다. 개발자·운영자 쪽 사본은 없습니다. |

카탈로그에는 **리뷰 문장, 점수, 수치, 이미지, 링크가 하나도 없습니다.** 이 조건은 자동 테스트(`tests/sources.test.cjs`)가 지킵니다.

## 2. 추천 점수는 무엇에 근거하나

- 제조사 지역(일본/유럽·미국)과 닙 굵기에 대한 **일반적인 경향 규칙**
- 사용자 본인이 입력한 시필 기록, 사용 평가, 잉입 이력
- 사용자가 **원문 확인을 체크한** 외부 리뷰 메모(체크하지 않으면 점수에 쓰이지 않습니다)

앱은 점수를 "비보정 비교용 추정"이라고 밝히고, 자료가 부족하면 그 사실을 함께 보여 줍니다.

## 3. 사용자가 외부 리뷰를 기록할 때

잉크 상세의 "외부 리뷰" 칸은 **링크(https://)와 직접 정리한 짧은 메모**를 위한 곳입니다. 화면에도 "리뷰 문장을 그대로 옮겨 적지 말라"고 안내합니다. 이 내용은 사용자 기기에만 저장되며 앱이 외부로 전송하지 않습니다.

## 4. 외부 접속과 개인정보

이 앱은 **로컬 우선**입니다. 입력한 내용은 기기 밖으로 나가지 않고, 가입·로그인·분석(추적) 도구가 없습니다.

| 접속 | 언제 | 보내지는 것 |
|---|---|---|
| 앱을 올려 둔 호스팅 주소 | 앱을 열거나 새 버전을 확인할 때 | 앱 파일 요청(일반적인 웹 접속 정보: IP, 브라우저 종류). 사용자 데이터는 없음 |
| 사용자가 입력한 사진 주소의 사이트 | 해당 사진을 화면에 표시할 때 | 이미지 요청(접속 정보) |
| **사용자가 직접 고른 AI 앱·서비스** (선택 기능) | 사용자가 사진 판독을 쓰려고 복사한 지침과 사진을 그 앱에 **직접** 붙여 넣을 때 | 사진과 복사한 지침(내 컬렉션의 브랜드 이름 목록, 시필 카드에서는 고른 만년필·잉크·종이). **이 앱은 전송에 관여하지 않으며** 사진을 받거나 저장하지 않습니다. 해당 서비스의 약관·개인정보 정책이 적용됩니다. |

이 목록 밖의 주소가 빌드에 들어오면 자동 테스트가 실패합니다. (글꼴도 외부 CDN 이 아니라 기기의 기본 글꼴을 씁니다.)
이전 버전에 있던 서버를 통한 사진 판독(외부 AI API 호출)은 제거되었습니다. 대신 **사용자가 자기 AI 앱에 복사·붙여넣기**로 쓰는 방식을 제공합니다(위 표의 마지막 행). 앱 자체는 AI 서비스에 접속하지 않습니다.

## 5. 내장 데이터를 더할 때의 규칙 (운영자용)

앞으로 카탈로그나 조사 자료를 늘릴 때는 아래를 지킵니다.

1. **사실만 담는다.** 제품명, 분류, 수치. 리뷰·블로그·포럼의 **문장은 복사하지 않는다.** 요약도 원문을 재서술한 수준이면 쓰지 않는다.
2. **출처를 남긴다.** 어떤 자료에서 정리했는지 기록하고, 가능하면 제조사 공식 자료를 우선한다.
3. **약관·라이선스를 확인한다.** 크롤링·스크래핑으로 모은 데이터는 넣지 않는다.
4. **이미지를 핫링크하지 않는다.** 소유권·추적·링크 깨짐 문제가 모두 있다.
5. **수치에는 측정 조건과 출처 등급을 붙인다.** 객관적 수치가 없는 항목은 비워 둔다(임의로 채우지 않는다).
6. 위 항목을 어기는 데이터가 들어오면 `tests/sources.test.cjs` 가 실패하도록 가드를 유지한다.

로드맵 4차의 "모두의 시필 평균"은 외부 리뷰 의존을 줄이는 방향입니다. 다만 사용자 기여 데이터를 모으려면 서버, 개인정보 처리방침, 동의 절차가 필요합니다(현재 구조인 "내 기기에만 저장"과 다른 설계).

## 6. 상표

브랜드·제품명은 제품을 식별하려는 목적으로만 표기합니다. 이 앱은 언급된 어떤 브랜드와도 제휴·후원·보증 관계가 없습니다.
