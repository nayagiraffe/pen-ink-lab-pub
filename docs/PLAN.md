## 방향 전환: 로컬 우선 웹앱(PWA)

구글 시트 동기화 방식(설치가 복잡하고 사용자마다 구글 설정이 필요)을 버리고, **기기 안에 저장하는 정적 웹앱**으로 바꿨습니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| L1 | 정적 호스팅용 빌드(`site/`), 글꼴 CDN 제거 | 완료 |
| L2 | 구글 동기화 코드·UI 제거, 저장 상태를 기기 기준으로 | 완료 |
| L3 | 백업 알림·영구 저장 요청·용량 경고·iPhone/Android 설치 안내 | 완료 |
| L4 | 엑셀(.xlsx) 저장, 인쇄/PDF | 완료 |
| L5 | PWA(오프라인·홈 화면 설치·아이콘·자동 업데이트) | 완료 |
| L6 | 구글 방식 파일 정리, 문서·배포 압축파일 | 완료 |
| L7 | 사진은 사용자의 AI 앱에 복사·붙여넣기(제품 등록, 시필 초안) | 완료 |
| L8 | 앨범·카메라 사진을 카드에 넣기(기기 안 저장, 사진 포함 .zip 백업·복원) | 완료 |
