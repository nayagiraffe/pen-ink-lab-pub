# 올리는 방법 (운영자용)

이 앱은 **정적 파일 몇 개**(HTML·아이콘·설정)만 있으면 돌아가요. 서버, 데이터베이스, 구글 계정이 필요 없어요. 아래 중 편한 곳에 올리면 주소 하나가 생기고, 사용자는 그 주소를 열면 돼요.

> **HTTPS 주소가 필요해요.** 홈 화면 설치와 오프라인 기능(서비스 워커)은 `https://` 주소(또는 `localhost`)에서만 동작해요. 아래 호스팅은 모두 HTTPS를 기본 제공해요.

## 올릴 파일

배포 압축파일의 **`사이트파일`** 폴더 **안의 내용 전체**를 올리세요. (폴더 자체가 아니라 그 안의 파일들)

```
index.html
manifest.webmanifest
sw.js
icons/ (아이콘 4개)
.nojekyll
```

개발자는 `npm run build` 로 `site/` 폴더를 직접 만들 수 있어요. 올리기 전에 `npm run serve` 로 `http://localhost:8080` 에서 미리 볼 수 있어요.

## 방법 1. GitHub Pages (무료, 추천)

> ⚠ GitHub Pages는 **무료 플랜에서는 공개(Public) 저장소만** 가능해요. 소스 저장소를 비공개로 두고 싶다면 **사이트 전용 공개 저장소를 따로** 만드세요. 사이트 저장소에는 빌드된 파일만 들어가니 소스를 공개하지 않아도 돼요.

1. GitHub에서 새 저장소를 만들어요. 이름은 예: `pen-ink-lab` (이 이름이 주소에 들어가요). **Public**으로.
2. 만든 저장소 화면에서 **uploading an existing file**을 누르고, `사이트파일` 폴더 **안의 파일들을 끌어다 놓은 뒤 Commit changes**.
   - 맥에서 `.nojekyll`은 숨김 파일이라 보이지 않을 수 있어요. 없어도 동작해요.
3. 저장소의 **Settings → Pages**로 이동해요.
4. **Source**를 **Deploy from a branch**, **Branch**를 `main` / `/ (root)`로 두고 **Save**.
5. 1~2분 뒤 같은 화면에 주소가 나와요: `https://내아이디.github.io/pen-ink-lab/`
6. 주소를 열어 확인하고, 사용자에게 이 주소를 알려 주세요.

### 업데이트
새 버전의 `사이트파일` 내용을 같은 방법으로 **다시 업로드(덮어쓰기)** 하면 돼요. 사용자는 다음에 앱을 열 때 새 버전을 자동으로 받아 둬요. (사용자 데이터는 그대로예요.)

### 소스에서 자동 배포 (선택 · 미검증)
소스 저장소를 공개로 두는 경우, GitHub Actions로 "푸시하면 자동으로 빌드·배포"를 만들 수도 있어요. 이 저장소에는 아직 이 설정을 넣지 않았고, 실제 GitHub에서 검증하지 못했어요.

## 방법 2. 다른 무료 호스팅

- **Cloudflare Pages / Netlify**: 사이트 만들기에서 `사이트파일` 폴더를 끌어다 놓는 방식(드래그 앤 드롭 배포)이 있어요. 비공개 소스와도 따로 쓸 수 있어요.
- **직접 운영하는 서버**: 위 파일들을 웹 서버 아무 폴더에 두면 돼요. HTTPS만 켜 주세요.

---

## ⚠ 주소를 바꾸면 사용자 데이터가 사라져 보여요

사용자 데이터는 **주소(도메인)별로 따로** 저장돼요. 그래서 호스팅을 옮기거나 GitHub 계정·저장소 이름을 바꿔서 **주소가 바뀌면, 기존 사용자의 데이터는 새 주소에서 보이지 않아요.**

- 처음 정한 주소를 **오래 유지**하세요.
- 꼭 옮겨야 한다면, 미리 사용자에게 **"백업 → 새 주소에서 복원"** 을 안내하세요.
- (같은 `내아이디.github.io` 안의 다른 저장소 주소끼리는 브라우저 저장 공간을 공유하지만, 이 앱의 저장 키는 고유한 이름이라 서로 충돌하지 않아요.)

## 올린 뒤 점검 (한 번만 직접 해 보세요)

실제 기기에서 확인해야 하는 항목이에요. 자동 테스트는 이 부분을 대신할 수 없어요.

- [ ] 주소가 `https://` 로 열리고, 화면이 정상으로 보인다
- [ ] iPhone Safari: 공유 → 홈 화면에 추가 → 아이콘으로 열린다 / 상단 안내(홈 화면에 추가)가 알맞게 보인다
- [ ] **iPhone: Safari 탭에서 입력한 데이터가 홈 화면 앱에 보이지 않는다** (안내가 필요한 이유를 직접 확인)
- [ ] Android Chrome: "앱으로 설치"가 뜨거나 메뉴에서 설치된다
- [ ] 비행기 모드에서도 앱이 열린다 (한 번 열어 본 뒤)
- [ ] 백업(JSON) → 다른 브라우저에서 복원이 된다
- [ ] 엑셀 저장 파일이 **Excel / Numbers / Google 스프레드시트** 중 쓰는 프로그램에서 열린다
- [ ] 인쇄 · PDF 저장이 휴대폰에서도 된다
- [ ] 새 버전을 올린 뒤 앱을 다시 열면 "새 버전이 준비됐어요"가 뜨고 데이터가 그대로다
